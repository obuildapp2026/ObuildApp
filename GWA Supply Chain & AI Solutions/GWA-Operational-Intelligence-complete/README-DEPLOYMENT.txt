GWA Operational Intelligence - deployment

1. Upload all files in this folder to the root of the GitHub Pages repository.
2. IMPORTANT: keep any existing Obranto files that are still used by the repository.
   This package does not contain reconstructed Obranto files because their original
   contents were not supplied as a complete repository export.
3. Before publishing QuickScan submissions, replace the endpoint in formspree-config.js
   with the real endpoint from the GWA QuickScan Formspree form.
4. CNAME is set to gwa-oi.nl.

The website itself uses the supplied GWA branding and a separate globe asset.
No invented Formspree endpoint is included.
